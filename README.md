# Прогнозирование RV S&P 500

Сравнение HAR, Ridge, Random Forest, MLP и Gamma-регрессии в прогнозе реализованной дисперсии S&P 500 на следующий торговый день. Основная задача — проверить, улучшает ли Gamma прогноз относительно классической HAR.

## Данные и метод

Используется дневная реализованная дисперсия из Oxford-Man, рассчитанная по пятиминутным доходностям. Последняя дата — 25.02.2022.

- Начальное обучение: 2012–2014.
- Валидация и выбор настроек по MAE: 2015.
- Тест: 04.01.2016–25.02.2022, 1537 торговых дней.

Признаки — RV предыдущего дня и средние за 5 и 22 предыдущих торговых дня. Модели переобучаются каждые 22 торговых дня на расширяющейся истории с 2012 года. Более ранние данные используются только для первых лагов. Пики RV сохраняются.

## Результат

| Метрика | HAR | Gamma | Снижение ошибки | 95%-й интервал снижения |
|---|---:|---:|---:|---:|
| MAE | 0,478283 | 0,415328 | 13,16% | 8,04–18,64% |
| RMSE | 1,702459 | 1,561590 | 8,27% | 4,23–20,10% |

Ошибки измеряются в %². Интервалы получены парным круговым блочным бутстрапом: 10 000 повторов, блок по 22 торговых дня. Для обеих моделей выбираются одинаковые блоки; модели внутри бутстрапа не переобучаются.

Оба интервала выше нуля, что поддерживает вывод о преимуществе Gamma на выбранном тесте. Интервалы рассчитаны отдельно для каждой метрики. Схема проверки уточнялась после первоначального анализа, поэтому результат исследовательский и требует проверки на новом периоде.
